状态：已接入项目。程序代码未改，只增加了安装打包。  
分发：两种都保留。非程序员用 `dist/DeskReminder-Setup.exe`；程序员用源码或 `python build.py` 打出的便携 exe。  
目标：安装包做成常见 Windows 软件那种安装 / 可搜索 / 可卸载。

## 1. 要达成什么

非程序员拿到的是 **安装程序**（`DeskReminder-Setup.exe`）。便携 exe 仍然保留，程序员可以自己打包或直接拷 `DeskReminder.exe`。

装完之后必须同时满足：

| 能力 | 验收 |
|------|------|
| 开始菜单能搜到 | 按 Win 键，输入 `Desk Reminder`，能搜到并打开 |
| 系统能卸载 | 「设置 → 应用 → 已安装的应用」里能看到 Desk Reminder，点卸载能卸干净程序文件 |
| 用户数据保留 | 任务仍存在 `C:\Users\<用户名>\.deskreminder\`，重装 / 卸载默认不删任务 |

对方电脑 **不需要** 安装 Python。源码不上传服务器；服务器（若以后有）只放已经打好的安装包。

---

## 2. 安装向导里要让用户选的（常规项）

按正规软件常见安装流程，向导里提供这些选项即可，不要做成复杂企业安装。

| 步骤 | 默认 | 说明 |
|------|------|------|
| 许可协议 | 展示即可 | 可先用简单免责声明；没有正式协议也先占位 |
| 安装位置 | 见「已拍板」：所有用户 / 仅为我，两套默认路径 | 允许改路径 |
| 开始菜单快捷方式 | **必选、默认勾选且不可取消** | 这是 Win 搜索能找到软件的前提 |
| 桌面快捷方式 | 默认勾选，可取消 | 有的人不想桌面多图标 |
| 装完立即运行 | 默认勾选，可取消 | 常规体验 |

暂不做：开机自启选项、自定义组件勾选、网络安装、多语言安装向导（向导用中文即可）。

---

## 3. 安装程序要做的（系统侧）

安装成功后，系统上应有：

1. **程序文件**  
   安装目录内是已打包好的 `DeskReminder.exe` 及运行所需文件（不必再让用户自己找 exe）。

2. **开始菜单快捷方式**（硬性）  
   写入开始菜单程序目录，显示名建议：`Desk Reminder`。  
   这样 Win 键搜索才能命中。图标用现有 `assets/icon.ico`。

3. **卸载信息**（硬性）  
   写入 Windows 卸载注册表，使「设置 → 应用」和「控制面板 → 程序和功能」都能看到：
   - 名称：Desk Reminder
   - 发布者：与项目一致即可（可暂用作者名 / 占位）
   - 图标：同上
   - 卸载命令：能删掉安装目录、开始菜单项、桌面快捷方式、卸载注册表本身

4. **权限**  
   向导里选「为所有用户」：UAC 一次，程序、开始菜单、卸载登记写给所有用户；桌面快捷方式若勾选，放公共桌面。  
   选「仅为我」：不提权，程序放当前用户目录，开始菜单、桌面快捷方式、卸载登记都只写当前用户。

---

## 4. 卸载时要清什么、不清什么

**要删除：**

- 安装目录里的程序文件
- 开始菜单快捷方式
- 安装时创建的桌面快捷方式
- 卸载注册表项

**默认不删除：**

- `C:\Users\<用户名>\.deskreminder\`（任务库、窗口配置、错误日志）

可选：卸载页加一句「是否同时删除本地任务数据」，默认不勾。第一期可以不做这个勾选，只要保证默认不删数据。

卸载后，Win 搜索里不应再出现 Desk Reminder；「已安装的应用」里也不应再列出。

## 5. 明确不改的部分

- 任务数据位置不变，仍与 exe 分离。
- 现有功能、界面、托盘行为不变。
- 开发者本地仍可用 `python main.py` 跑源码；`python build.py` 仍先打出 exe，再由安装脚本去包一层。

## 6. 第一期不做

- 微软商店上架
- 自动更新 / 在线检查新版本
- 代码签名（没签名时 SmartScreen 可能提示「未知发布者」，属预期；以后再补证书）
- 废掉便携 exe：`python build.py` 和 `dist/DeskReminder.exe` 继续保留，和安装包并存

## 7. 实现时注意（备忘，不现在做）

- 安装包包的是 **已经编好的 exe**，不是 `.py` 源码。
- 用 Inno Setup，和现有 `build.py` 衔接：先打 exe，再打安装包。
- 开始菜单快捷方式的「名称 / 图标」决定 Win 搜索展示；卸载项的 `DisplayName` 决定系统应用列表展示，两者应一致。
- 验收时至少测：安装 → Win 搜索打开 → 关软件 → 设置里卸载 → 再搜索应搜不到。
